Agentshive — AI Agent Registry

Next.js 16TypeScriptSupabaseMCPVercel Edge

Problem Installing AI agents meant manual copy-paste of prompt files across Claude Code, Codex, n8n, and LangChain — no shared source of truth.

Architecture Next.js 16 + Supabase (Postgres + Auth) on Vercel with edge-cached APIs; a CORS-enabled REST endpoint serving prompts as markdown, plus an @agentshive/mcp server exposing search/get/install tools over stdio.

Impact Structured metadata, APIs, and search workflows make 150+ agents discoverable across multiple development ecosystems, with one-command installs via curl, WebFetch, or MCP.
